# Control

## What is control (in CS)?
- Setting a target
- Taking a measurement
- Commanding a device to reduce the difference between the target and the measurement
- Example:
  - Air conditioning
    - Target: Desired temperature
    - Measurement: Actual temperature

## IPO (Input-process-output) model
- Input:
  - Sensors that take a measurement of a variable
- Process:
  - A computer calculates a difference between the target and produces a control output
- Output:
  - Actuators execute the output

### Types of sensors
- Accelerometer
- Gyroscope
- Thermometer
- Humidity sensor
- Infrared sensor
- Light sensor
- Motion sensor
- Etc.

### Actuators
- Require energy to work
- Require a signal from the controller
