# Expressions
- An expression is a kind of entity that `can be evaluated`
- They also exist in mathematics:
  ```1+2``` is an expression
- In python:
```py
    1 + 2           # This is a mathematical expression
    True or False   # This is a logical expression
    x == 5          # Also a logical expression, it checks whether x is equal to 5, can be True or False
    5               # Technically, this is also an expression

    #-----------------------------------------------------
    x = 5           # This is >>not<< an expression, it's an assignment
```
