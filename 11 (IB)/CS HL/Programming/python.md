# <span style="color:#fabd2f">Python
- High-level (--> Very similar to human language)
- Interpreted (--> Only translated into machine code when running)
- General-purpose
- `Easy to learn`
- Uses `indentation instead of brackets`:
  - In C:
    ```CPP
    if (something){
        // everything between {} belongs to the _if_ statement
        // This comment is inside the _if_
    }

    //This comment is outside the _if_
    ```
  - In python:
    ``` python
    if something:
        # This comment is inside the _if_ statment
        # Because it is indented (pushed to the right)
    # This comment is _outside_ the if
    ```
- Extensive libraries --> Large standard library so you don't have to code your own tools
- Open-source --> Developed by the community
- Applications:
  - Data science
  - AI
  - Web development
### Disadvantages
- Slow execution (slower than other languages)
- High memory usage (because of flexible data types)
- Global Interpreter Lock --> makes parallelism difficult
- Runtime errors --> Weakly-typed nature causes runtime errors often
